# Security policy

Please do not report vulnerabilities in public issues. Use GitHub's
[private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)
on this repository.

We especially want to hear about ways a repository's content could:

- Expose API keys
- Run commands on a user's machine
- Bypass the [repository config restrictions](docs/configuration.md#settings-a-repository-cannot-set)

Only the latest release receives security fixes.
